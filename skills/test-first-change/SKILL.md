---
name: test-first-change
description: Add a feature or fix by writing a failing test first, then the code.
---
1. Write a test that captures the required behavior. Run it and confirm it fails for the right reason.
2. Implement the smallest change that makes it pass.
3. Run the full suite. Fix regressions before moving on.
4. Refactor only with the tests green.
5. Submit with a summary that names the tests you added.
